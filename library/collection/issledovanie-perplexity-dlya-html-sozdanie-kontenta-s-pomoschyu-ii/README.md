# 🔍🛠️Perplexity Researcher to HTML Web Page

> Исследует тему через Perplexity, пишет статью и делает из неё HTML-страницу с Tailwind CSS.

| | |
|---|---|
| **Категория** | [🤖 Сборная 300+ (ИИ и контент)](../README.md) |
| **Запуск** | вебхук, вызов из другого воркфлоу |
| **Сервисы** | OpenAI, Telegram |
| **Узлов в схеме** | 38 |
| **Нужные учётные данные** | `httpCustomAuth`, `httpHeaderAuth`, `openAiApi`, `telegramApi` |

## Как запустить

1. Скачайте [`workflow.json`](workflow.json) (кнопка **Download raw file** на GitHub).
2. В n8n: **Workflows → Import from File** и выберите файл.
3. Откройте узлы с учётными данными и подключите свои — ключей в файле нет.
4. Проверьте параметры узлов (адреса, id таблиц, чатов и т. п.) под себя и включите воркфлоу.
